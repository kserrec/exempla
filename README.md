# Exempla

Learn programming from exemplary real-world source code.

Exempla is a curated, GitHub-native catalog of public software repositories.
Choose a programming language, choose an SDC difficulty level, and find code
that is worth reading at that stage of your learning.

SDC keeps three different questions visible:

- **S — Size:** how much meaningful implementation code must be navigated?
- **D — Difficulty:** how demanding is the code itself to understand?
- **C — Complexity:** how demanding is the software as a whole system?

The catalog separates difficulty from quality. A repository receives an SDC
score only after it passes a quality gate covering real-world purpose, source
quality, architecture, naming, tests, documentation, traceability, and
educational value.

## Project status

The initial 20-language, 200-repository catalog is under construction. The
complete implementation sequence and completion criteria live in
[PLAN.md](PLAN.md).

## Principles

- Real software, never tutorials, exercises, toys, or contrived examples.
- Source quality matters more than popularity.
- Every score is explained with evidence.
- GitHub browsing works without a website or custom application.
- Automation checks facts and consistency; humans judge code and architecture.
- The SDC heuristic stays deliberately small and understandable.
